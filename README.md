# Transfer–Calibration: Groundwater Paper B

Reproducibility workspace for a retrospective evaluation of geographic model transfer and prediction-interval calibration across 23 Indian states.

**Status: evidence inventory and validation in progress.** No experimental code, numeric results, or model artifacts have yet been authenticated for publication in this repository. Repository creation does **not** establish independent reproducibility of the published analyses.

## Intended scope

Only validated, author-owned experimental protocols, scripts, derived evaluation outputs, integrity manifests, and instructions will be added after source-to-result reconciliation. Manuscript source, journal PDF, original CGWB datasets, and unrelated project materials are excluded.

## Important methodological boundaries

- Provisional composite well identifiers were used; authenticated CGWB well IDs and a corresponding ID-sensitivity experiment are unavailable.
- Exact original HGB predictors and training hyperparameters have not yet been independently authenticated.
- Evaluation is retrospective, based on observation dates; independent historical release-time verification is unavailable.
- Leave-one-state-out evaluation concerns cross-state model transfer with local well-history information, not forecasting at previously unmonitored wells.

## Reproduction status

No claim of executable end-to-end reproduction is made until the experimental scripts, inputs/outputs, dependencies, and checksums pass a documented verification gate.

## Data

Original CGWB data are not redistributed here. Consult the source data provider and the study's documented source inventory for lawful acquisition.

## Release policy

This repository is a staging workspace. A verified tagged research release and public code-availability claim will follow only after audit and author approval.
